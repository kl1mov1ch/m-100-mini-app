# Формат М100

Одна строка результата — один оплачиваемый вид работы. Название и единица берутся из структурного шаблона, когда тип компонента ему соответствует. Для нового вида работы используй краткое предметное название.

Размеры, марки, артикулы, системы и повторение работы на другой странице не создают новый вид работы. Различие материалов, монтаж и демонтаж, обычный и взрывозащищённый обратный клапан сохраняются. Указанные в шаблоне радиальные вентиляторы объединяются в одну оплачиваемую строку.

Колонки результата: номер, наименование, единица, количество по смете, расценка, сумма, примечание. В примечании только количество упоминаний на каждой странице: «стр. 23 — 3 упомин.; стр. 24 — 2 упомин.».

Количество складывается из ячеек количества подходящих строк текущего PDF после устранения повторного извлечения одной физической строки. Количество упоминаний является отдельной величиной. В одной строке суммируются совместимые единицы.

Лист с готовым контрольным примером служит проверкой структуры. Его количества и цены относятся только к исходному объекту. В новых PDF извлекай их из новых исходных данных. Отсутствующее значение остаётся пустым.

Комплектность одной поставляемой установки не превращай в дополнительную установку её узлов. Пусконаладочные ведомости используются для контроля оборудования, не прибавляются к монтажной спецификации. Расходный материал может оформляться комплектом; состав и исходные единицы сохраняются внутри обработки.
