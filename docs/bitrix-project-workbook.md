# Рабочая книга проекта в Битрикс24

## Перенос сметы

1. На портале откройте «Разработчикам» → «Готовые сценарии» → «Другое» → «Входящий вебхук». Выберите право «Диск (disk)». Владелец вебхука должен иметь возможность создавать папки и изменять файлы на своём Диске.
2. Скопируйте адрес из поля «Вебхук для вызова REST API». В M-100 откройте «Настройки» → «Вебхуки Битрикс24», нажмите плюс, укажите имя и сохраните адрес.
3. Откройте в мини-приложении нужный объект и вкладку «Таблица». Если показано предупреждение о незавершённом импорте, сначала проверьте и подтвердите смету.
4. Нажмите «Создать рабочую книгу». Для объекта с прежним шаблоном используйте «Создать из данных объекта». Если мастер уже заполнил прежний шаблон вручную, сначала импортируйте его через «Импортировать прежнюю книгу».
5. Введите название папки и вид работ, выберите вебхук и нажмите «Создать». Например, для «Детский сад» и «Вентиляция» получится путь **Детский сад / Вентиляция / Отчётность проекта.xlsx**.
6. Откройте книгу из карточки. В рабочем журнале проверьте наименование, плановый объём, ставку и один знакомый день. В новом объекте без работ будет столбец на текущую дату. Исходные позиции можно внести в лист «Смета» и открыть проверку исходных листов в настройках подключения.

## Ссылка на просмотр

Рабочая запись привязана к идентификатору файла и вебхуку. Публичная ссылка нужна тем, с кем делятся книгой. Получатель такой ссылки сможет прочитать в том числе расценки и примечания.

Если портал разрешает внешние ссылки, приложение получает ссылку автоматически. Проверить её можно во вкладке «Таблица» → «Доступ для просмотра». Если портал отказал, откройте файл на Диске, выберите «Поделиться» и разрешите просмотр по ссылке. Вставьте публичную ссылку на Excel в появившееся поле и нажмите «Проверить и сохранить ссылку». При запрете публичных ссылок на уровне портала решение принимает его администратор. Сотрудник с правом редактирования файла по-прежнему может отправлять отчёты через вебхук.

[Инструкция Битрикс24 по вебхукам](https://apidocs.bitrix24.ru/local-integrations/local-webhooks.html) · [Получение публичной ссылки и причины отказа](https://apidocs.bitrix24.ru/api-reference/disk/file/disk-file-get-external-link.html)

## Проверка на тестовом объекте

- [ ] Создайте книгу из локальной сметы с известной расценкой и одним заполненным днём. Сверьте число работ, объём, бригаду и дневную сумму.
- [ ] Откройте «Текстом», опишите работу и нажмите «Применить». Проверьте карточки и повторно откройте форму — исходное описание должно остаться. Публикация происходит после отдельного подтверждения отчёта.
- [ ] Увеличьте объём одной работы на единицу и отправьте отчёт. Сверьте ту же строку на Диске. Прибавка к сумме дня должна равняться расценке за единицу. Проверьте, что в папке один файл отчётности.
- [ ] На объекте без работ проверьте наличие текущей даты и отсутствие вымышленных позиций.
- [ ] Откройте ссылку на просмотр в приватном окне. Проверьте, что она ведёт в нужную книгу и сотрудник без права редактирования не может её изменить.
- [ ] На телефоне проверьте длинную расценку, выбор вебхука и загрузку следующей страницы списка «Из сметы».
