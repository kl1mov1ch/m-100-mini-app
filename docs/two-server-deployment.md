# Два сервера

Проект располагается в `/var/miniApp/m-100` на каждом сервере. На сервере в России работают Nginx, собранный React и FastAPI с рабочими базами. На сервере в Германии работают приватное распознавание речи и выход к внешним API. Это учитывает небольшой объём памяти и диска машин; контейнерный запуск из основной инструкции остаётся альтернативой для более мощного сервера.

Службы находятся в `deploy/systemd`: `m100-app`, `m100-link`, `m100-speech`. Пример Nginx — `deploy/nginx.native.conf`. Сервер приложения слушает только 127.0.0.1:8000, речь — только 127.0.0.1:8766. Германия соединена с Россией постоянным SSH-туннелем. Ключ туннеля разрешает только необходимые назначения и не даёт командной оболочки. Проверка host key обязательна.

В `deploy/secrets/app.env` на российском сервере задаются `APP_ENV=production`, абсолютный `APP_DATABASE`, `APP_ALLOWED_ORIGINS`, `TELEGRAM_ADMIN_IDS`, `TELEGRAM_BOT_TOKEN`, `LLM_PROXY_URL=socks5h://127.0.0.1:40001`, `TELEGRAM_PROXY_URL=socks5h://127.0.0.1:40001`, `WHISPER_REMOTE_URL=http://127.0.0.1:8767` и общий `SPEECH_SHARED_TOKEN`. В Германии `deploy/secrets/speech.env` содержит тот же токен и `WHISPER_MODEL=small`. Файлы секретов имеют ограниченные права и не входят в Git.

Корень проекта принадлежит администратору, рабочая папка `data` — пользователю службы. Службы не работают от root. Исходники обновляются из Git; перед перезапуском проверяются Python, React и конфигурация Nginx. При переносе данных используется приватный архив `scripts/data_archive.py` с исправлением путей объектов для Linux.

Старые службы и каталоги отключаются и удаляются после проверки новой версии. Резервная копия старого сайта и настроек хранится отдельно в `/var/backups/m100-legacy` с закрытыми правами. Сертификаты обслуживает Certbot, обновление Nginx выполняется после успешного продления.

Для аватаров туннель также разрешает `t.me:443`. Сервер получает фото по проверенной ссылке Telegram из данных входа, а при её отсутствии использует Bot API. Адреса других сайтов не проксируются. Кэш фото обновляется при изменении ссылки профиля; изображение в шапке имеет фиксированные квадратные размеры и круглую обрезку.
